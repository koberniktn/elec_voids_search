## Результаты

- **Искусственные вакансии LiCl и Li₃PO₄ воспроизведены:** в обеих структурах найденная позиция удалённого Li проходит геометрию, координационный и Li–Li-фильтры. Отклонение координат составляет **0,000166 Å** для LiCl и **0,042151 Å** для Li₃PO₄.
- **LATP:** правильно определены все **6 известных незанятых Li-позиций**, оставшихся после случайного распределения лития по частично заселённым сайтам. Им соответствуют **3 симметрично неэквивалентных кандидата**, проходящих оба финальных фильтра. Всего геометрический отбор прошли 46 кандидатов.
- **LLZO + Ga:** после геометрии осталось **35 кандидатов**; независимо проверку Li–Li прошли **17**, координацию — **16**. Оба критерия одновременно выполняются для **1 кандидата**.
- **LGPS, Li₁₀Ge(PS₆)₂:** после геометрии осталось **5 кандидатов**; Li–Li-фильтр прошли **3**, координационный — **0**. Поэтому кандидатов, проходящих оба критерия, нет. Это результат текущих настроек отбора; он не доказывает отсутствие подходящих физических позиций.

## Файлы

- [summary.csv](summary.csv) — количества кандидатов по этапам.
- [summary_norm.csv](summary_norm.csv) — те же количества, нормированные на формульную единицу.
- [branch_steps.csv](branch_steps.csv) — результаты каждого шага финальных маршрутов.
- [reference_recovery.csv](reference_recovery.csv) — восстановление известных вакансий.
- [metadata.json](metadata.json) — настройки и сведения о сохранённом прогоне.
- `<структура>/candidates.csv` — ID, координаты, принадлежность этапам и оценки фильтров.
- `<структура>/cif/` — CIF для VESTA: **01–02** сетка и Вороной, **03** общий список, **04** кластеры, **05** симметрия, **06** геометрия, **07** координация, **08** Li–Li, **09** оба фильтра.

В CIF полости обозначены фиктивными X-маркерами; при пустой выборке остаётся только каркас. Сырые кандидаты до кластеризации могут совпадать по координатам. Новые запуски сохраняют визуализации только в CIF.

Запуск — [full_pipeline.ipynb](../full_pipeline.ipynb), параметры — [PARAMETERS.md](../../../elec_voids_search/docs/PARAMETERS.md).
