# Полный пример поиска полостей

Откройте [full_pipeline.ipynb](full_pipeline.ipynb) в Python-окружении с зависимостями из `requirements-notebook.txt` и выполните ячейки сверху вниз. Ноутбук также содержит сохранённые результаты выполненного прогона.

Входы семи структур включены в `inputs/`; локальные абсолютные пути не нужны. Степени окисления и параметры отбора видны в ноутбуке. Исходный код пакета находится в `../../elec_voids_search/`.

Поиск: сетка и Вороной независимо → объединение → кластеры → симметрия → геометрия. После геометрии доступны независимые координационный и Li–Li-фильтры и оба порядка их последовательного применения.

Результаты — в `voids_gallery/`: итоговые количества, шаги веток, контроль известных позиций и метаданные воспроизводимости. Для каждого соединения — одна таблица всех кандидатов с исходными ID, координатами, флагами этапов и оценками фильтров; радиусы и занятые контрольные сайты.

В каждой папке соединения `cif/` содержит файлы для VESTA, `vasp/` — те же этапы в формате POSCAR. X — фиктивные маркеры полостей. Файлы с X предназначены для просмотра, а не для расчёта VASP. При отсутствии кандидатов файл содержит исходный каркас. В VESTA настройте цвет и радиус X через Properties → Atoms.

Этапы: 01 сетка, 02 Вороной, 03 общий список, 04 кластеры, 05 симметрия, 06 геометрия, 07 координация, 08 Li–Li, 09 оба критерия. 07 и 08 — независимые ветки. 09 — общее пересечение: для обоих порядков одинаково, поэтому файлы не дублируются.

Повторное выполнение создаёт новую папку с временной меткой. Исторические результаты и архив базовой версии не изменяются. Ионная геометрия и сходство окружений — критерии скрининга; энергетическая устойчивость здесь не рассчитывается.

После полного прогона координационная часть обновлена отдельно: обязательная первая сфера, независимые допуски длин и углов. Актуальные таблицы встроены в notebook. Для продолжения на сохранённой геометрии используется `refresh_coordination(example=None, config=None)` из `refresh_coordination.py`; ему можно передать свой `VoronoiCoordinationConfig`. Эта функция перезаписывает только координационные результаты и пересечения в `voids_gallery/`.
