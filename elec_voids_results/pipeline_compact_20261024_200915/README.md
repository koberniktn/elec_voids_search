# VESTA: этапы отбора

01_grid и 02_voronoi — независимые сырые кандидаты; 03_combined — общий список; 04_merged — представители близких кластеров; 05_nonequivalent — после симметрии; 06_geometry — итог. Все CIF содержат исходный каркас и фиктивные X-маркеры.

removed_01_merged — удалённые при кластеризации; removed_02_nonequivalent — удалённые по симметрии; removed_03_geometry — не прошедшие геометрию. Их следует сравнивать с соответствующим основным CIF. При нулевом числе маркеров CIF содержит только каркас.

Для просмотра в VESTA откройте CIF, настройте радиус/цвет X в Properties → Atoms; X — маркер, не внедрённый литий. Разные этапы сохраняют неизменные координаты. candidates.csv содержит общую нумерацию, происхождение и флаги этапов, а также геометрические оценки проверенных представителей. Пустые радиусные поля у ранее отброшенных точек означают, что их геометрия не вычислялась.

summary.csv — количества; vacancy_recovery.csv — контроль искусственных вакансий; site_radii.csv — использованные радиусы каркаса. Других промежуточных выгрузок и визуализаций нет.

Все семь расчётов завершены; число кандидатов не возрастает после объединения сырых списков, координаты не перемещаются. Все использованные радиусы конечны. Проверены количество X-маркеров и читаемость CIF-данных во всех 63 файлах. GUI VESTA не запускался.

Обе искусственные вакансии найдены в конечной выборке: LiCl — 0.00016556 Å, Li3PO4 — 0.04215082 Å от известной позиции с учётом симметрии.

Ограничения: связные компоненты при пороге 0.75 Å образуют цепочки; максимальное расстояние от представителя до члена кластера достигает 3.31 Å в LATP и 3.83 Å в LLZO. Это может объединять разные близкие полости. Найденные вакансии не доказывают полноту остальных кандидатов. Контроль занятых Li-сайтов проходит 8/10 в LATP, 0/50 в LLZO, 4/20 в LGPS, 0/6 в Li3PO4, 2/2 в LiCl; такие отказы показывают ограничения жёсткой радиусной модели. Параметры по результатам этого прогона не менялись.
