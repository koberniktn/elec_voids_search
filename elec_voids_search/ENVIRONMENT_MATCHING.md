# Сходство координационного окружения: отдельный финальный этап

Модуль environment_matching.py добавлен отдельно. Утверждённые поиск, геометрия, фильтр расстояний до Li и их настройки не изменены. Исходные программы также не менялись.

```python
from elec_voids_search.environment_matching import (
    EnvironmentMatchConfig, screen_environment_similarity,
)

result = screen_environment_similarity(
    structure, candidates_after_probe_distance,
    oxidation_states={"Li": 1, "La": 3, "Zr": 4, "Ga": 3, "O": -2},
    probe_element="Li", probe_oxidation_state=1,
    config=EnvironmentMatchConfig(),
)
final_candidates = result["environment_passed"]
```

Кандидаты передаются таблицей с candidate_id и frac_x/frac_y/frac_z. Предыдущие этапы не запускаются. Каждый кандидат сравнивается со всеми симметрийно неэквивалентными занятыми сайтами пробного элемента; достаточно совпадения хотя бы с одним. Возвращаются environment_evaluated, environment_passed, environment_rejected и environment_indeterminate. Координаты и ID не изменяются.

## Определение окружения

Для Li+ рассматриваются анионы каркаса с явно заданным отрицательным зарядом. В общем случае берутся атомы противоположного знака заряда, исключая пробный элемент. Это первая координационная сфера, а не полный многогранник всех соседей.

Соседи собираются в периодической сфере 6 Å, без вставки пробника и создания суперячейки. Первая сфера определяется правилом d ≤ 1.25 d_min. Одинаковое правило применяется к порам и занятым сайтам. Если сфера не помещается внутри радиуса поиска, выдаётся ошибка с просьбой увеличить cutoff. Частичные заселённости требуется предварительно разрешить.

## Условия сходства

Все условия должны выполняться одновременно:

1. Одинаковые числа соседей каждого химического элемента в первой сфере.
2. RMS-различие отсортированных по элементам длин связей ≤ 0.15 Å.
3. RMS-различие отсортированных углов по парам элементов ≤ 12°.
4. RMSD векторов соседей после оптимального ортогонального совмещения с перестановкой одинаковых элементов ≤ 0.25 Å.

Центр совмещения — сайт: перенос и масштабирование запрещены. Отражение допускается по умолчанию (инверсия окружения не считается изменением координации); allow_reflection=False разрешает только собственные вращения. Координаты кандидата при этом не меняются: совмещение используется исключительно для сравнения копий векторов.

Точное сопоставление снимает неоднозначность одних только распределений углов. Перестановки ограничены настраиваемым бюджетом 40320. Если бюджет превышен у пары, она явно indeterminate; при отсутствии подтверждённого совпадения с другими сайтами такой кандидат не объявляется прошедшим.

## Настройки и ограничения

EnvironmentMatchConfig содержит все указанные пороги, численный допуск 1e-8 и symprec 0.10 Å. Это начальные инженерные настройки, не универсальные физические границы. Они были объявлены до сравнительного прогона, а не изменены для получения положительного результата.

Первая сфера по множителю d_min может скачкообразно меняться у пограничных соседей. Проверена чувствительность множителя 1.20/1.25/1.30/1.40. Для новых соединений нужны проверки устойчивости или мягкая/взвешенная координация. Метод специально сравнивает локальную анионную координацию, не тождество всего окружения: дальние катионы, дефекты и энергия внедрения требуют отдельной оценки. Новый тип междоузлия без занятого аналога закономерно может не пройти этот фильтр.

## Сравнительная проверка

Результаты: ../elec_voids_results/environment_comparison_20261024_213319/REPORT.md. На 21 кандидате после всех предыдущих этапов приняты LLZO–Ga #1129 и две известные Li-вакансии: LiCl #28, Li3PO4 #122. Из 43 геометрически прошедших кандидатов LATP в отдельной диагностике не прошёл ни один; эти точки ранее были отклонены по Li и в финальную выборку не возвращались.

В сравнении old easy/strong использовались их исходные функции, а у двух old radial-методов явно добавлен порог cosine ≥ 0.95: в исходниках такого порога вообще нет, только ранжирование. Поэтому радиальные количества относятся к этому дополнительно объявленному правилу.

Сохранение двух известных вакансий подтверждено численно, но двух положительных контролей недостаточно для оценки полноты/доли ложных срабатываний. Для следующей валидации нужны независимые вакансии разных типов LLZO и LATP, а не ослабление допуска до заранее желаемых количеств.
