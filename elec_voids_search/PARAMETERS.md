# Параметры поиска и геометрического отбора

Все действующие значения по умолчанию определены в `config.py`, в `SearchConfig`. Notebook использует тот же объект, а не отдельную копию настроек. Значения ниже — исходный рабочий профиль, выбранный по предыдущему анализу; новая последовательность этапов и новые допуски ещё не проверены запуском.

| Параметр | По умолчанию | Единицы / назначение |
| --- | --- | --- |
| `grid_resolution_A` | 0.20 | Å; желаемый шаг сетки Grid |
| `grid_search_cutoff_A` | 5.0 | Å; радиус поиска ближайшего атомного центра, не размерный фильтр |
| `grid_symprec_A` | 0.10 | Å; точность симметрии для сокращения сетки; `None` отключает сокращение |
| `grid_minima_window` | 3 | Нечётный размер окна локальных экстремумов, 3 означает 3×3×3 узла |
| `grid_r_min_A` | 1.0 | Å; параметр Grid для отчётов/генерации конфигураций, здесь не фильтрует поле min_dists |
| `grid_empty_framework` | `False` | Существующие атомы пробного элемента сохраняются; True удаляет их только из сеточной задачи |
| `grid_verbose` | `False` | Подробный вывод Grid и списка максимумов |
| `probe_element` | `"Li"` | Пробный элемент; атомный номер для Grid определяется автоматически |
| `probe_oxidation_state` | 1 | Степень окисления внедряемого иона, отдельно от зарядов каркаса |
| `voronoi_image_range` | 1 | Образы от −n до +n по каждой оси: 1 = 27 образов, 2 = 125 |
| `voronoi_boundary_tolerance` | 1e-9 | Безразмерный допуск отбора вершин внутри дробной ячейки |
| `voronoi_qhull_options` | `None` | Дополнительные настройки scipy.spatial.Voronoi; None оставляет настройки SciPy |
| `merge_distance_A` | 0.75 | Å; порог попарной близости в общем списке до симметрии; None отключает кластеризацию |
| `merge_representative` | `"largest_center_distance"` | Максимум расстояния до ближайшего атомного центра |
| `merge_grouping` | `"connected"` | Исходные связные компоненты; `"representative"` — явный альтернативный режим |
| `symmetry_symprec_A` | 0.10 | Å; точность SpacegroupAnalyzer исходной структуры |
| `symmetry_tolerance_A` | 0.10 | Å; совпадение позиций после операции симметрии, строго меньше порога |
| `symmetry_angle_tolerance_deg` | 5.0 | Градусы; угловой допуск SpacegroupAnalyzer, −1 включает автоматический выбор spglib |

## Почему такие значения

- Сетка 0.20 Å — сбалансированный исходный шаг из прежних расчётов: обе искусственные вакансии находились после отключения подавления на 2 Å. В LLZO при шаге 0.10 Å было около 2.2 млн узлов вместо 262 тыс. для 0.20 Å. Для подробного поиска доступен шаг 0.10 Å; он увеличивал покрытие Вороной-выборки, но создавал и дополнительные несовпадающие максимумы.
- Окно 3×3×3 сохраняет прежнее правило локальности. Увеличение окна меняет набор максимумов и не является простым уточнением сетки.
- Отсечение относительно глобального максимума отключено, чтобы не отбрасывать локальные кандидаты до последующих физических проверок. Подавление близких максимумов внутри Grid не включается: близость обрабатывается только после объединения методов.
- Общий порог увеличен до 0.75 Å для удаления близких вариантов одной полости. Это стартовое значение порядка радиуса Li+, не проверенный оптимум. Прежний порог 2 Å терял известные вакансии, поэтому он не возвращён. Все исходные координаты сохраняются для аудита.
- Допуск симметрийного сопоставления снижен с 0.25 до 0.10 Å, чтобы следующий этап не отменял консервативность общего объединения: готовая функция учитывает и тождественную операцию, поэтому также может склеивать близкие точки. Это рабочее стартовое значение, а не измеренный оптимум полноты симметрийной редукции.
- `grid_symprec_A` и `symmetry_symprec_A` оставлены 0.10 Å, как в исходных расчётах; это допуски определения симметрии, а не пороги размера полости.
- По умолчанию сохраняется максимум d_min среди точек обоих методов, независимо от источника. Исторические ошибки Вороного 0.00017/0.042 Å и сетки 0.152/0.185 Å относятся к двум прежним вакансиям и не валидируют текущий порог объединения.
- 27 образов и поиск ближайшего центра до 5 Å сохранены из исходных скриптов. Для вытянутых/косоугольных ячеек можно увеличить число образов, для крупных пустот — радиус поиска. При бесконечных расстояниях Grid выдаёт понятную ошибку; автоматического скрытого увеличения порога нет.

## Выбор представителя кластера

- `"voronoi"`: первая вершина Вороного, если есть; иначе первая точка группы.
- `"grid"`: первая сеточная точка, если есть; иначе первая точка группы.
- `"first"`: первая точка группы, как в исходной ячейке объединения.
- `"largest_center_distance"`: точка с максимальным расстоянием до ближайшего атомного центра. Это не свободный ионный радиус.

Координаты на всех этапах неизменны. По умолчанию используются исходные связные компоненты; цепочки могут давать размах больше порога. В candidate_clusters.csv сохраняется max_distance_to_representative_A.

## Изменение настроек

```python
from dataclasses import replace
from elec_voids_search import DEFAULT_CONFIG, SearchConfig
from elec_voids_search.run_search import run_search

# Все значения по умолчанию:
settings = SearchConfig()

# Более подробная сетка; остальные настройки сохраняются:
fine_settings = replace(settings, grid_resolution_A=0.10)

# Любой параметр можно изменить явно:
settings = replace(
    settings,
    grid_resolution_A=0.20,
    merge_distance_A=0.75,
    merge_representative="largest_center_distance",
    merge_grouping="connected",
    symmetry_tolerance_A=0.10,
    voronoi_image_range=1,
)
result = run_search(input_cif, new_output_folder, config=settings)
```

Альтернативы: `config={"grid_resolution_A": 0.1}` или `run_search(..., grid_resolution_A=0.1)`. Неизвестные имена и недопустимые значения вызывают ошибку, а не игнорируются. Для совместимости принимаются прежние `resolution`, `search_cutoff`, `symprec`, `symmetry_tolerance`, `merge_distance`, `image_range`, `grid_params`. Явные новые имена имеют приоритет; `symprec` задаёт оба допуска определения симметрии, словарь `grid_params` меняет только Grid.

Объект настроек неизменяемый: используйте `replace`, чтобы параметры одного запуска не менялись незаметно при подготовке следующего. Во всех выходных JSON записываются полностью разрешённые настройки.

Допуск восстановления вакансии 0.25 Å задаётся отдельно в тестовом notebook: это критерий оценки известной позиции, не параметр отбора кандидатов. При `grid_empty_framework=True` сетка и Вороной используют разные наборы атомных центров; для сопоставления методов сохраняйте False.

## Геометрия после симметрии

| Параметр | Дефолт | Назначение |
| --- | --- | --- |
| `geometry_minimum_fit_fraction` | 1.0 | Доля найденного по окружению радиуса пробника; 1.0 проверяет полный размер |
| `geometry_allow_ionic_fallback` | True | Последний запасной вариант: только ionic radius для точно заданного заряда, после интерполяции/ближайшего Shannon |
| `geometry_probe_radius_override_A` | None | Явный положительный радиус пробника; имеет приоритет над таблицами |
| `export_cif` | False | Запись CIF с X; при False сохраняются только CSV/JSON |
| `geometry_probe_spin` | `""` | Spin пробника: `""`, `"High Spin"`, `"Low Spin"` |
| `geometry_overlap_tolerance_A` | 0.005 | Å; малый явный допуск для пограничных решений; строгий вариант 0.0 |
| `geometry_numeric_tolerance_A` | 1e-7 | Å; численный допуск проверки зазора |
| `geometry_neighbor_cutoff_A` | 12.0 | Å; search_cutoff CrystalNN и радиус окружения для контролей |
| `geometry_oxidation_states` | {} | Обязательные ручные заряды всех элементов; неполный словарь вызывает ошибку |
| `geometry_host_radius_overrides_A` | {} | Положительные радиусы по символу или строковому индексу сайта; индекс приоритетнее |
| `geometry_spin` | `""` | Spin для радиусов каркаса, отдельно от spin пробника |

Радиус пробника определяется отдельно для каждой полости в неизменных координатах. Входной вызов: `run_search(path, output, probe_element="Li", probe_oxidation_state=1, geometry_oxidation_states={"Li": 1, "Cl": -1})`; для Na+ меняется символ на Na. Фиксированного радиуса Li и контактной поправки нет. Старые geometry_mode и geometry_li_radius_A больше не поддерживаются: неизвестные параметры вызывают ошибку вместо молчаливого игнорирования.

В исходном Вороной-скрипте был коэффициент 0.75; здесь 1.0 выбран по требованию полного размера. При явном уменьшении коэффициента результат означает смягчённый геометрический скрининг. Независимый порог d_min=1 Å не применяется.

CrystalNN и Shannon вызываются через исходные неизменённые функции. Недостающие точные радиусы разрешаются по [RADIUS_POLICY.md](RADIUS_POLICY.md); если численного источника нет вообще, нужен явный override, иначе ошибка входных данных. Физические ограничения модели и происхождение блоков: [GEOMETRY_ANALYSIS.md](GEOMETRY_ANALYSIS.md).


Пробник вставляется в копию исходной периодической ячейки без изменения дробных координат. Расширения ячейки в этом этапе нет; параметр размера расширения удалён. Периодические копии пробника участвуют в построении Вороного, поэтому КЧ и радиусы могут отличаться от прежнего расчёта с расширением.

## Актуализация политики

Все ручные заряды назначаются до вызова исходных функций. Для отсутствующих КЧ действует интерполяция/ближайший Shannon того же иона; стандартный ionic_radius — последний запасной источник. Подробности и причины приоритета одной шкалы радиусов: [RADIUS_POLICY.md](RADIUS_POLICY.md).

geometry_overlap_tolerance_A=0.005 введён после пограничного отказа известной LiCl-вакансии при зазоре −0.002975 Å. Допуск откалиброван на этом контроле, не прошёл независимую валидацию. strict_zero_overlap_fit отдельно отмечает отсутствие любого перекрытия с численным допуском 1e-7 Å. Параметры сетки, симметрии, доля полного радиуса не изменялись для получения положительных количеств в электролитах.

## Порядок применения

Независимые сырые кандидаты сетки и Вороного → общий список и кластеры близких точек → симметрийный отсев → геометрия. Координаты неизменны. Геометрия только фильтрует; дополнительных этапов после неё нет. Итог — result["geometry"].

Симметрийный допуск 0.10 Å не увеличивается вместе с пространственным порогом. Подробности: [CANDIDATE_MERGING.md](CANDIDATE_MERGING.md). Новая конфигурация подготовлена без выполнения тестов и notebook.
