# Продолжение отбора: расстояние до занятого пробного элемента

Новый этап добавлен отдельными модулями. Утверждённый поиск, геометрия, SearchConfig и базовые результаты не изменены.

```python
from elec_voids_search.probe_separation import ProbeSeparationConfig
from elec_voids_search.continue_screening import continue_screening_from_saved

settings = ProbeSeparationConfig(probe_element="Li", distance_tolerance_A=0.10)
result = continue_screening_from_saved(
    input_cif, saved_baseline_candidates_csv, new_output_folder, config=settings,
)
```

Для таблицы геометрически прошедших пор в памяти можно вызвать `screen_probe_separation(structure, geometry_candidates, config=settings)` напрямую.

Для каждого занятого Li находится расстояние до ближайшего другого Li в бесконечной периодической структуре. Усредняется по **всем** занятым сайтам, с их реальной кратностью. При одном Li в ячейке ближайший другой Li — периодическая копия. Используются кратчайшие периодические расстояния и кратчайшая ненулевая трансляция, без создания суперячейки.

Затем для каждой геометрически прошедшей поры находится ближайший занятый Li. Пора отклоняется, когда `d(пора, Li) + distance_tolerance_A + numeric_tolerance_A < mean_Li_nearest_neighbor_A`. Равенство проходит. По умолчанию абсолютный допуск 0.10 Å и численный 1e-8 Å. 0.10 Å — начальный явно заданный допуск, не результат калибровки по вакансиям; его можно уменьшить до нуля или задать другое значение. Пора, которая немного ближе среднего в пределах допуска, сохраняется.

`probe_element` можно сменить. Степени окисления на этом расстояниевом этапе не используются; существующая геометрическая оценка не пересчитывается. Нет перемещения, повторной кластеризации или повторного симметрийного отсева пор. Частично заселённые структуры следует предварительно разрешить; отсутствие занятого пробного элемента даёт ошибку, поскольку среднее не определено.

## Занятые позиции и симметрия

`occupied_sites.py` содержит побуквенные копии `site_has_element`, `site_composition` и `get_nonequivalent_occupied_sites` из strong_voids_screening.py, включая исходное форматирование. Происхождение и хеши: OCCUPIED_SITES_SOURCE.json. Для вызова оригинальной функции необходимы структура, SpacegroupAnalyzer и символ пробного элемента.

Список симметрийно неэквивалентных занятых позиций рассчитывается отдельно. Для каждой группы сохраняются исходные индексы, заселённости, кратность и координаты первого представителя. Все реальные занятые позиции остаются в расчёте среднего и расстояний до пор. Настройки симметрии отдельные: 0.10 Å и 5° по умолчанию.

## Результаты

- `probe_distance_passed`: прошли геометрию и новый критерий.
- `probe_distance_rejected`: прошли геометрию, не прошли новый критерий.
- `probe_distance_evaluated`: обе группы в одной таблице, с исходными ID/координатами, ближайшим занятым сайтом, расстоянием, средним, допуском и статусом.
- `occupied_probe_sites`: все занятые позиции и их ближайшие соседи.
- `occupied_probe_nonequivalent`: симметрийно неэквивалентные занятые позиции.

Экспортируется одна общая таблица кандидатов вместо копий для каждой группы. В VESTA: 07_probe_distance_passed.cif — каркас и X-маркеры прошедших оба критерия; removed_04_probe_distance.cif — каркас и X-маркеры отклонённых новым критерием. Пустая группа даёт CIF только с каркасом. Этап 06_geometry находится в сохранённых базовых результатах и повторно не записывается.

Это дополнительный эвристический фильтр расстояний, не энергетический критерий устойчивости. Локально неоднородные Li-подрешётки могут иметь допустимые позиции с расстояниями меньше глобального среднего. Восстановление известных вакансий проверяется после нового отбора, а не предполагается заранее.
